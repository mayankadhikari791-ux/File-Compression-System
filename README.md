# 🚀 File Compression System (C++14 / Modern OOP)

A high-performance, modular, lossless **File Compression System** implemented in C++14. Designed and engineered by a collaborative team of 4 members, featuring dual compression engines (**Huffman Coding** and **PackBits Run-Length Encoding**), bit-level I/O serialization, a custom `.fcs` container format, high-precision benchmarking, and an interactive CLI.

## 📦 Binary File Format (`.fcs`)

All compressed files generated by this system use the custom `.fcs` format:

```text
+-----------------------+-------------------+----------------------+--------------------+--------------------+-------------------------+
| Magic Bytes (4 bytes) | Algo ID (1 byte)  | Orig Size (8 bytes)  | Meta Len (4 bytes) | Metadata Payload   | Compressed Data Payload |
| "FCS\x01"             | 1 = Huff, 2 = RLE | uint64_t             | uint32_t           | (e.g. Serial Tree) | Bit-packed payload      |
+-----------------------+-------------------+----------------------+--------------------+--------------------+-------------------------+
```

## 💻 CLI Usage & Commands

### 1. Interactive Menu Mode
Run without any arguments to launch the friendly interactive interface:
```bash
bin\fcs.exe
```

### 2. Compress a File
```bash
# Compress with Huffman Coding (default)
bin\fcs.exe -c document.txt document.fcs -a huffman

# Compress with Run-Length Encoding (RLE)
bin\fcs.exe -c repetitive_data.bin compressed.fcs -a rle

# Enable verbose step-by-step progress logging
bin\fcs.exe -c document.txt document.fcs -a huffman -v
```

### 3. Decompress a File
The decompressor automatically detects the algorithm and original file size from the `.fcs` container header:
```bash
bin\fcs.exe -d document.fcs restored_document.txt -v
```

### 4. Benchmark & Compare Algorithms
Runs all available compression algorithms on the file, measures elapsed time and memory footprints, and validates bit-for-bit data integrity:
```bash
bin\fcs.exe -b document.txt
```
